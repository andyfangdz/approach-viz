# Agent Notes

Lightweight decision records for approach-viz. These are not a second source of truth — `AGENTS.md` and `docs/` stay current with shipped behavior. Notes here capture _why_, alternatives, and deferred simplification work that would otherwise vanish into a PR body.

Layout: `{lifecycle}/{class}/yyyy-mm-dd-topic.md`

- `proposed/` — not yet built
- `implemented/` — shipped; keep facts (paths, names) current
- `rejected/` — declined, kept only while it prevents a tempting mistake

Class `simplification` means removing surface area without adding a capability.
